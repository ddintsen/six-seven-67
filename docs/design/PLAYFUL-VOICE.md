# Six Seven: playful voice

User direction: the name is a Six Seven joke. The product can know this without turning trading into a joke. The original numeral characters bring the shrug; market questions, prices, risks and settlement stay explicit.

## Where the joke belongs

Use one short joke in a catalogue introduction, an empty state or a footer. Keep the exact market question intact. Avoid repeating the meme on every row, button or status. The brand remains **67**; “Six Seven” is its spoken name.

| Context | Suggested copy | Supporting copy or action |
| --- | --- | --- |
| Catalogue introduction | Big questions. Questionable confidence. | Explore markets |
| Alternative catalogue heading | What's your take? | Synthetic questions. Local demo quotes. |
| Secondary catalogue heading | More things to have an opinion on. | None needed |
| Empty portfolio | All takes. No positions. | Your simulated positions will appear here. · Explore markets |
| No search results | Nothing by that name. Yet. | Try another question or clear your filters. · Clear filters |
| Disconnected portfolio | Your takes need a home. | Connect a demo wallet to track simulated positions. · Connect demo wallet |
| Demo wallet connected | Demo wallet connected | Demo credits have no monetary value. |
| Footer | A little unserious. Clear about the rules. | Prototype only. No real-money trading. |

## Transaction language stays sober

Actions: **Choose outcome**, **Review simulated trade**, **Confirm simulated trade**, **View position**. The review shows amount, denomination, shares, fees, payout basis and maximum loss before confirmation.

| Condition | Explicit message |
| --- | --- |
| Changed quote | The quote changed. Review the updated amount before confirming. |
| Insufficient balance | Your demo balance is too low for this amount. |
| Unavailable quote | No executable demo quote is available. You cannot place this trade. |
| Rejected signature simulation | Approval was rejected. No simulated trade was placed. |
| Failed transaction simulation | The simulated transaction failed. Your demo balance was not changed. |
| Stale source | Source information is out of date. Local settlement is not confirmed. |
| Outcome under review | The proposed outcome is under review. Local settlement is not confirmed. |
| Settlement pending | The source outcome is final. Settlement in 67 is still pending. |

Only show a statement about unchanged balance when the implementation guarantees it. Preserve the existing technical state names. Never use “easy money,” “free win,” “guaranteed,” “trustless,” “risk-free,” or invented activity as punchlines. Do not celebrate an unsettled position as a win.

## Mascot use

`public/six-seven-mascot.svg` is an original flat vector pair: red six, yellow seven, alternating palms-up gesture. It can sit beside the catalogue introduction or an empty state. Keep it away from price charts and transactional confirmation, where it could imply a data signal or endorsement. Render with an empty `alt` when surrounding copy already expresses its decorative purpose; use “Six and Seven shrugging” only when the illustration itself conveys useful context. Do not animate prices, add a 67% quote, or let the illustration obscure the product's main action.
